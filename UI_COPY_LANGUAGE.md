# UI/CLI Copy Language

User-facing product UI and CLI copy in Dev Config Hub must be Simplified Chinese by default.

Scope includes Tauri UI text, CLI output, prompts, confirmations, validation messages, backup/restore copy, profile-management copy, help text, and user-facing errors.

Keep technical identifiers as-is: command names, flags, profile IDs, file paths, environment variables, config keys, schema fields, JSON/TOML keys, tool names, provider names, and product names such as Claude, Codex, OpenCode, and Dev Config Hub.

When adding a new user-facing surface, write the explanatory copy in natural Simplified Chinese and keep code-level identifiers unchanged.
